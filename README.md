VOID SALVAGE — pilot a salvage drone through a debris field: harvest shards, dodge the void, survive the waves. A complete arcade arena shooter with waves, enemy variety, a boss every fifth wave, dash, combo scoring, pickups, synthesized sound, and a start / pause / game-over loop.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome. WASD or arrows to move, mouse to aim, hold click to fire, Shift to dash, P to pause, M to mute.
